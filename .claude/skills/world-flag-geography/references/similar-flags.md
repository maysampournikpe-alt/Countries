# Visually similar flag groups

Each group lists confusable flags and the cue that separates them. Verify against current official flags before shipping.

| Group | Distinguishing cue |
|---|---|
| Chad / Romania | Nearly identical blue-yellow-red verticals. Chad's blue is darker (indigo); Romania's blue is lighter cobalt. |
| Andorra / Moldova / Romania / Chad | Andorra and Moldova have a coat of arms in the yellow band; Andorra's arms has cows and a mitre, Moldova's has an eagle. |
| Indonesia / Monaco / (Poland inverted) | Red over white. Indonesia 2:3, Monaco 4:5. Poland is white over red. |
| Ireland / Côte d'Ivoire | Ireland: green at the hoist (left). Côte d'Ivoire: orange at the hoist. |
| Italy / Mexico | Mexico has the eagle emblem in the centre and darker green. |
| Netherlands / Luxembourg / (Paraguay, Croatia) | Luxembourg's blue is lighter and flag longer; Netherlands darker blue. Paraguay has a central seal; Croatia has a checkerboard shield. |
| Russia / Slovakia / Slovenia / Serbia | Same white-blue-red family. Slovakia: shield with double cross near hoist. Slovenia: shield with mountain (Triglav) top-left. Serbia: red-blue-white order with crowned eagle. |
| Australia / New Zealand | Australia: white stars, plus a large 7-point star under the Union Jack. NZ: four red stars with white border, no star under the Union Jack. |
| Senegal / Mali / Guinea / Cameroon | Senegal: green star centre. Mali: plain green-yellow-red. Guinea: plain red-yellow-green (reversed). Cameroon: green-red-yellow with star. |
| Colombia / Ecuador / Venezuela | Colombia: yellow band is half the flag, no emblem. Ecuador: same layout with coat of arms. Venezuela: equal bands, arc of stars. |
| Honduras / Nicaragua / El Salvador / Guatemala | Honduras: five blue stars. Nicaragua & El Salvador: central coat of arms (Nicaragua's triangle with rainbow; El Salvador's with the text ring). Guatemala: vertical bands. |
| Norway / Iceland / Denmark / Finland / Sweden | Nordic crosses. Norway red with blue cross; Iceland blue with red cross; Denmark red with white cross; Finland white with blue; Sweden blue with yellow. |
| Egypt / Syria / Iraq / Yemen / Sudan | Egypt: golden eagle. Yemen: plain red-white-black. Iraq: green Arabic script. Sudan: green triangle at hoist. Syria (2025+): green-white-black with three red stars — verify current. |
| Jordan / Palestine / (Sudan, Kuwait) | Jordan: red triangle with white seven-point star. Palestine: plain red triangle. Kuwait: black trapezoid at hoist. |
| Qatar / Bahrain | Both white serrated hoist. Qatar: maroon, 9 points, long 11:28. Bahrain: red, 5 points. |
| Luxembourg / Netherlands | See above. |
| Haiti / Liechtenstein | Haiti: horizontal blue-red with central arms. Liechtenstein: blue-red with gold crown at top-left. |
| Ghana / Bolivia / Lithuania / Ethiopia | Ghana: black star. Bolivia: red-yellow-green (red top). Lithuania: yellow-green-red. Ethiopia: green-yellow-red with blue disc. |
| Cuba / Puerto Rico (territory) | Only Cuba is in the core set. Cuba: blue stripes, red triangle. |
| Malaysia / USA / Liberia | Malaysia: yellow crescent and 14-point star. Liberia: one white star, 11 stripes. USA: 50 stars, 13 stripes. |
| Panama / Dominican Republic | Panama: quartered with stars. Dominican Republic: white cross with coat of arms. |
| Monaco / Singapore / Indonesia | Singapore has crescent and five stars on the red. |
| Benin / Guinea-Bissau / Togo / Mali | Benin: vertical green at hoist, yellow-red horizontals. Guinea-Bissau: red vertical with black star. |
| Thailand / Costa Rica | Thailand: red-white-blue-white-red with wide central blue. Costa Rica: blue-white-red-white-blue with wide central red. |
| Burundi / Jamaica | Both saltire shapes; Burundi has white saltire with red stars disc; Jamaica gold saltire on green/black. |
